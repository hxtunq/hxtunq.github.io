Python là ngôn ngữ đa năng với hệ sinh thái thư viện phong phú và linh hoạt nhất hiện nay, phục vụ toàn diện từ thu thập dữ liệu tự động (web scraping), tính toán ma trận hiệu năng cao (`NumPy`), thao tác bảng dữ liệu tốc độ cao (`Pandas`, `Polars`), đến xây dựng API và triển khai ứng dụng web tương tác.

### Tài liệu tham khảo
- **[Python for Data Analysis (3e)](https://wesmckinney.com/book/)** — *Wes McKinney (tác giả thư viện Pandas)*  
  Cẩm nang thực tế toàn diện về thao tác dữ liệu với `NumPy`, `Pandas`, `Jupyter Notebook` và xử lý chuỗi thời gian.
- **[Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/)** — *Jake VanderPlas*  
  Giáo trình miễn phí trình bày rõ ràng 4 trụ cột: IPython, NumPy, Pandas và Matplotlib/Scikit-Learn.
- **[Automate the Boring Stuff with Python](https://automatetheboringstuff.com/)** — *Al Sweigart*  
  Rất phù hợp cho người mới bắt đầu: học cách viết script tự động xử lý file, duyệt web, bóc tách dữ liệu và thao tác bảng tính.

### Thư viện tính toán và Xử lý dữ liệu
- **NumPy:** Nền tảng tính toán mảng đa chiều hiệu năng cao và đại số tuyến tính.
- **Pandas & Polars:** Thao tác dữ liệu dạng bảng. Trong đó Polars được viết bằng Rust với khả năng xử lý song song vượt trội.
- **Matplotlib & Seaborn:** Bộ đôi trực quan hóa tĩnh tiêu chuẩn trong hệ sinh thái Python.
- **Plotly & Altair:** Thư viện vẽ biểu đồ tương tác trên nền tảng web linh hoạt.
